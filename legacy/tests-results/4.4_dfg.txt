## TC 상세 설명

TC-1: dfg_analyze(NULL) → NULL 반환, dfg_destroy() T** 모델 검증
      (이중 해제, NULL 포인터 안전 처리)
TC-2: 직선 5개 명령어 블록에서 명령어별 Def/Use 비트셋 검증
      - mov rax, rbx  → def=RAX(bit0),   use=RBX(bit3)
      - add rcx, rdx  → def=RCX(bit1),   use=RCX|RDX
      - xor rsi, rsi  → def=RSI(bit6),   use=0 (self-clear 특수 처리)
      - cmp rax, rbx  → def=0,           use=RAX|RBX
      - ret           → def=0,           use=RAX(bit0)
TC-3: 2-블록 함수(jmp)에서 block0.out → block1.in 전파 확인
TC-4: 동일 레지스터 재정의 시 gen_mask=kill_mask=RAX(bit0) 확인
TC-5: 조건 분기(jne) 3-블록 함수에서 모든 후행 블록 in_mask에 RAX 전파 확인
