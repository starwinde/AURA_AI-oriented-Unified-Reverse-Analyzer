```

        │                       └─► Phase 5.7 (바이너리 패치: Zydis)

              ├─► Phase 8 (디컴파일 뷰: 8.5)    ◄─ 5.2 완료 필요
              └─► Phase 8 (나머지: 8.6~8.7)

[UI 통합 태스크 — Phase 8 이후 진행]
  2.5 디스어셈블러 UI 통합  ◄─ 2.4 + 8.4 완료 필요
  5.6 디컴파일 뷰 UI 통합   ◄─ 5.5 + 8.5 완료 필요

Phase 6 (LLM 로컬) ──► Phase 7 (LLM 클라우드)
Phase 2~8 완료 ──► Phase 9 (통합 테스트)
Phase 9 완료   ──► Phase 10 (문서화·배포)

Phase 11 (확장 기능) ──► Phase 12 (Ghidra Parity)
  11.19 (Xref UI) ◄─── 12.1 (Xref 백엔드)
  11.10 (Stack Layout) ◄─ 12.23 (스택 프레임 백엔드)
  11.20 (재귀 디스어셈블) ◄─ 12.4 (Full 재귀)
  11.21 (FLIRT) ──► 12.7 (인라인 탐지)

Phase 12 (Ghidra Parity) ──► Phase 13 (Decompiler v2)
  13.1 (Pass Manager) → 13.2~13.5, 13.8, 13.12, 13.14~13.15
  13.8 (Loop Detect) → 13.6, 13.16, 13.17
```

> **병렬 개발 가능 구간**: Phase 6/7 (LLM 연동)은 Phase 1.2만 완료되면 시작할 수 있어 Phase 2~5와 **동시에** 진행 가능하다. 사용자가 병렬 진행을 원할 경우 이 구간에서 작업을 나눌 수 있다. 단, 기본 실행 순서는 순차(Phase 2~5 → Phase 6~7)이며, 사용자가 명시적으로 지시할 때만 병렬 진행한다.
