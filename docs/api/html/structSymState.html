Detailed Description

SymState — 단일 실행 경로의 전체 상태

분기 발생 시 sym_state_clone()으로 복사하여 각 경로가 독립 보유한다. 직선 실행은 sym_step()이 in-place로 업데이트한다.

레지스터 인덱스: x86_64: RAX=0, RCX=1, RDX=2, RBX=3, RSP=4, RBP=5, RSI=6, RDI=7, R8~R15=8~15 ARM64: X0~X30=0~30, SP=31
