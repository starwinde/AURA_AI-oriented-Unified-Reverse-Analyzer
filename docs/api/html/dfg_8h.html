dfg.h — AURA 데이터 흐름 분석(DFG) 공개 API

Phase 4.4: CFG 위에서 Reaching Definition 분석을 수행하고 각 명령어별 Def/Use 비트셋과 블록별 Gen/Kill/In/Out 비트셋을 제공한다.

의존성:

  • cfg.h : Cfg, BasicBlock (입력, borrow)

레지스터 비트셋: uint32_t의 하위 16비트 사용. bit k = 레지스터 인덱스 k. x86_64: RAX=bit0, RCX=bit1, RDX=bit2, RBX=bit3, RSP=bit4, RBP=bit5, RSI=bit6, RDI=bit7, R8=bit8 .. R15=bit15.

설계 근거: Tasks.md 4.4 DoD 레지스터 인덱스 → 비트 마스크

dfg_analyze — CFG에서 DFG 분석 수행

3단계:

  1. 각 BasicBlock의 명령어를 순회하여 명령어별 Def/Use 비트셋 계산
