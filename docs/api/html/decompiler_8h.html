◆ IrType

enum IrType

decompiler.h — AURA 디컴파일러 공개 API (SSA 기반 IR)

Phase 5: CFG + DFG → SSA IR → 최적화 → Pseudo-C 생성 파이프라인.

의존성:

  • cfg.h : Cfg, BasicBlock (리프팅 입력)
  • dfg.h : DfgResult (def/use 정보 보조)
  • aura.h : AuraAddr, AuraError (disasm.h/cfg.h transitively 포함)

설계 근거: docs/design/decompiler.md, Task 5.1 DoD

소유권 모델: ir_lift()가 IrFunc를 heap 할당하여 반환 (호출자 소유). ir_func_destroy(&func) — T** 모델, 호출 후 *func == NULL 보장. IrType — SSA 피연산자 타입

타입 판정 우선순위:

  1. 피연산자 크기(al=INT8, ax=INT16, eax=INT32, rax=INT64)
  2. LEA 패턴 / 포인터 역참조 → PTR
  3. CMP/TEST 결과 → BOOL
  4. 불확실 → INT64 fallback

ir_lift — CFG + DFG → 원시 IrFunc (SSA 미완성 단계)

BasicBlock을 IrBlock으로 1:1 변환하고 기계어를 IR 명령어로 리프팅한다. DfgResult의 def/use 비트셋을 활용해 레지스터 사용을 추적한다. 이 단계에서는 φ-function이 삽입되지 않으며 SSA 형태가 아니다. SSA 완성을 위해 반드시 ir_build_ssa()를 이어서 호출해야 한다.

Parameters
cfg분석 대상 CFG (borrow, NULL 허용 — NULL이면 NULL 반환)
dfgDFG 분석 결과 (borrow, NULL 허용 — 타입 추론 품질 저하)
name함수 이름 (NULL이면 "sub_<hex>" 자동 생성)
func_addr함수 시작 가상 주소
Returns
성공 시 IrFunc 포인터 (호출자 소유), 실패 시 NULL

◆ ir_infer_types()

AuraError ir_infer_types ( IrFunc *  func)

ir_infer_types — SSA IR 변수 타입 추론 (in-place)

ir_build_ssa() 완료 후 호출한다. IrVal.type 필드를 in-place 갱신한다. 전파 규칙:

  • 피연산자 크기: ir_lift()에서 이미 설정된 레지스터 크기 기반 타입 유지
  • COPY: dst.type = src0.type
  • 산술/비트 연산: 더 넓은 피연산자 타입 전파
  • 시프트: 좌측 피연산자 타입 전파
  • PHI: 모든 incoming 값 중 가장 넓은 타입
  • PTR: src가 PTR이면 COPY/ADD/SUB dst도 PTR로 전파
  • 불확실: IR_TYPE_INT64 fallback (변경 없음)
Parameters
funcSSA IR (ir_build_ssa 완료 후)
Returns
AURA_OK 또는 에러 코드
