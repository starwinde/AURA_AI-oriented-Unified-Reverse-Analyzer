Detailed Description

mapped_file.h — mmap 기반 파일 I/O 레이어 공개 API

B안 2레이어 (D-10) 설계: MappedFile은 파일 I/O 전담 레이어 1이다. open() + mmap()으로 파일을 메모리에 매핑하고 FileInfo(레이어 2)에 소유권을 이전하거나, 직접 사용 후 mapped_file_destroy()로 해제한다.

설계 근거: docs/design/parser.md §2.1, D-6 (mmap 확정), D-10 (B안) MappedFile — open() + mmap() 결과 보유 구조체

mapped_file_open()으로 생성한다. 소유권은 file_info_create()에 이전하거나 mapped_file_destroy()로 직접 해제한다.

소유권 규칙:

  • fd : close() 책임 — mapped_file_destroy() 내부에서 수행
  • map : munmap() 책임 — mapped_file_destroy() 내부에서 수행
  • path : strdup() 복사본, free() 책임 — mapped_file_destroy() 내부에서 수행
