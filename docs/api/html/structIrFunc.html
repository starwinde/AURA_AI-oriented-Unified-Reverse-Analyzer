Detailed Description

IrFunc — IR 함수 단위 (최상위 컨테이너)

ir_lift()로 생성하고 ir_func_destroy()로 해제한다.

소유권: blocks : heap, IrFunc 소유. 각 IrBlock이 자신의 하위 자원을 소유. ir_func_destroy() 한 번으로 전체 트리 해제.
