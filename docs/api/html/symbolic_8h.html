sym_step — 단일 명령어 심볼릭 실행

insn에 해당하는 명령어의 효과를 st에 적용한다. insn은 borrow (소유권 이전 없음). 전역 상태를 변경하지 않는다 (동일 입력 → 동일 출력).

분기 명령어의 경우 st를 한쪽 경로로 업데이트한다. 나머지 경로는 호출자가 sym_state_clone() 후 처리한다.

Parameters
eng실행 엔진 (아키텍처 정보 보유)
st갱신할 실행 상태 (in-place)
insn실행할 명령어 (disasm_run() 결과)
Returns
AURA_OK, AURA_ERR_NOT_SUPPORTED (미지원 명령어), 또는 에러 코드
