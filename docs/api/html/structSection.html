Detailed Description

Section — ELF/PE/Mach-O 섹션을 포맷 중립으로 표현한다.

소유권 규칙: name : strdup() 복사본, section_destroy()에서 free() data : MappedFile의 mmap 내부 포인터 (file->map + offset) 읽기 전용, free() 절대 금지, MappedFile 수명 동안만 유효

포맷별 필드 매핑: docs/design/parser.md §5
