cfg.h — AURA 제어 흐름 그래프(CFG) 공개 API

Phase 4.3: 디스어셈블 결과에서 BasicBlock을 식별하고 블록 간 제어 흐름 엣지를 연결하는 CFG를 구축한다.

  • disasm.h : DisasmResult (명령어 배열 입력)
  • aura.h : AuraAddr, AuraError (disasm.h가 포함)
