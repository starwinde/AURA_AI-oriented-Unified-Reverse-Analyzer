Detailed Description

Symbol — ELF/PE/Mach-O 심볼을 포맷 중립으로 표현한다.

소유권 규칙: name : strdup() 복사본, symbol_destroy()에서 free() demangled : __cxa_demangle 반환값 직접 소유, NULL 허용 (C 함수 또는 실패) symbol_destroy()에서 free() (NULL 안전)

표시 이름은 symbol_display_name() 인라인 함수로 조회한다.
