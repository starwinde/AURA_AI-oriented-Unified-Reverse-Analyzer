Detailed Description

IrBlock — IR BasicBlock

cfg_build()의 BasicBlock과 1:1 대응. id는 원래 Cfg.blocks[] 인덱스와 동일하게 할당한다.

소유권: instrs, pred_ids, succ_ids, dom_front_ids : heap, IrBlock 소유. ir_func_destroy에서 모두 해제.
