enum AuraLogLevel

logger.h – AURA global logging facility

Four severity levels: DEBUG, INFO, WARN, ERROR. DEBUG output is suppressed by default; enable with aura_log_set_level(AURA_LOG_DEBUG) or the –verbose CLI flag.

Usage: AURA_LOG_D("loaded %d instructions", count); AURA_LOG_I("parsing %s", path); AURA_LOG_W("section .text not found, falling back"); AURA_LOG_E("elf_parser_load failed: %s", aura_error_str(err));
