Detailed Description

DfgBlockInfo — 단일 BasicBlock의 데이터 흐름 집합

gen_mask : 이 블록이 외부로 공급하는 정의 집합 (블록 내 def된 레지스터) kill_mask : 이 블록에서 재정의되는 레지스터 집합 in_mask : 블록 진입 시점에 도달하는 정의 집합 (Reaching Def 입력) out_mask : 블록 종료 시점에 도달하는 정의 집합 (Reaching Def 출력) insns : 블록 내 명령어별 DfgInsnInfo 배열 (heap, DfgBlockInfo 소유) insn_count: insns 배열 원소 수
