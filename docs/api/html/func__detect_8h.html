func_detect.h — AURA 함수 경계 탐지 및 Call Graph 공개 API

Phase 4.5: .text 섹션 전체 디스어셈블 결과에서 함수 경계를 휴리스틱으로 탐지하고 함수 간 직접 호출 관계를 Call Graph로 구성한다.

탐지 전략 (우선순위 순):

  1. push rbp + mov rbp, rsp — 표준 x86_64 프롤로그
  2. push rbp 단독 — 약식 프롤로그
  3. sub rsp, N — 스택 프레임 할당 (leaf 함수 등)
  4. FileInfo->symbols 의 AURA_SYM_FUNCTION 심볼 주소

의존성:

  • disasm.h : DisasmResult (입력 배열, borrow)
  • file_format.h : FileInfo, Symbol (심볼 이름 보조, NULL 허용)

설계 근거: Tasks.md 4.5 DoD 외부 함수 또는 미확인 callee를 나타내는 센티넬

func_detect — 디스어셈블 결과에서 함수 경계 탐지 및 Call Graph 구성

4단계:

  1. 프롤로그 패턴 스캔으로 함수 시작 후보 수집
  2. 심볼 테이블 보조 (fi != NULL이면 AURA_SYM_FUNCTION 심볼 추가)
  3. 후보 정렬·중복 제거 후 함수 범위 결정
  4. call 명령어 스캔으로 Call Graph 엣지 구성
