Detailed Description

FileInfo — 파싱 결과를 보유하는 64바이트 정렬 구조체

file_info_create(MappedFile **)로 생성한다.

  • aligned_alloc(64, sizeof(FileInfo)) 사용 (직접 malloc/calloc 금지)
  • 성공 시 *mf_ptr 소유권 인수 후 *mf_ptr = NULL 무효화

file_info_destroy(fi)로 해제한다.

  • 해제 순서: symbols → sections → file (MappedFile) → fi 자체

mmap 주소는 fileinfo_map() / fileinfo_map_size() 인라인 함수로만 접근한다.
